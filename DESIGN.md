# VSTMailer interface
Mode: Operate. The approved product and user's Velion asset guide this implementation; remaining design choices are builder proposals.

Use an ink navy navigation rail, warm near-white working canvas and emerald primary actions. Keep operational lists dense but readable. Use self-hosted Geist Sans for prose and Geist Mono for code and identifiers. Typography: 14px body, 12px metadata, 30px page heading. 8px spacing rhythm. 10px controls and panels with thin neutral borders. Avoid invented growth statistics and decorative charts; the overview visualizes actual message counts. Empty states should lead directly to sender setup and a first test email.

Tokens: ink #071d22; accent #087f5b; accent-hover #066448; canvas #f5f7f6; surface #ffffff; text #142b2b; muted #52645f; line #dfe7e2; focus #087f5b; error #b42318. Side navigation 232px, content max 1440px. Mobile navigation opens a compact menu and tables scroll within their container. All input labels visible, focus rings clear, feedback announced, and real errors preserved.
